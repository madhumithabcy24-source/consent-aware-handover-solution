Machine Learning & Deep Learning Model Architecture

Technical explanation of model architectures, feature extraction, and decision support scope.

Machine Learning

1. Relevance Classifier

Architecture: TF-IDF Vectorizer + Logistic Regression

Purpose:

Classify whether a piece of session information is relevant for client handover between helpline workers.

Why this model?

  • Explainability: Linear model coefficients clearly reveal which n-grams contribute to relevance predictions.
  • Confidence Scores: Logistic regression outputs calibrated probabilities (predict_proba).
  • Efficiency: Fast to train and execute on synthetic/de-identified session records.

Example Input/Output:

Input: "Client wants to improve study routine and requested a follow-up."
Output: Relevant (Confidence: 92%)
Deep Learning

2. Sensitivity Detector

Architecture: TextVectorization → Embedding → LSTM → Dense → Sigmoid

Purpose:

Detect whether session text contains potentially sensitive disclosures requiring privacy masking.

Why LSTM?

  • Sequential Context: Captures contextual word dependencies in text sequences.
  • End-to-End Serialization: Embedded TextVectorization layer ensures seamless model loading.

Example Input/Output:

Input: "Client disclosed private personal health history and family trauma."
Output: Sensitive (Confidence: 94%)

⚠️ Prototype Scope & Safety Disclaimer

This system is a prototype decision-support tool, NOT a clinical, medical, or psychological diagnostic system.

  • The Deep Learning model only classifies text as potentially sensitive or non-sensitive based on keyword pattern sequences.
  • The model does NOT understand human emotions, diagnose mental health conditions, or make clinical decisions.
  • Human counsellors and social workers remain fully responsible for final handover decisions.
  • Client consent choices unconditionally override all ML/DL model predictions in every instance.
